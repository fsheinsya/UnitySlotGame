# Slot(学園祭の展示品)
こちらはスロットを製作をさせていただきました。
実際には同じ絵柄を合わせるゲームで、タイミングを合わせて止めるゲームとなっております。
## 概要
私は学園祭でスロットを製作をして、学内を熱狂させたいと思ってスロットを作って熱狂させたい！と思いまして作成させていただきました。
## 実装をした主な機能
- リールの調整
- ボタンの実装
## 苦労したところ
リールと止めるところで閾値を操作をしてリールの停止位置を指定をするのですが、その調整が難しかった記憶があります。
止めたい場所がずれていたことが多かったので修正にかなり時間かかかりました
## 工夫した点
ここではUIの配置を意識しました。
他の人がプレイをしてストレスが感じないように配置を意識しました。
## 今後作成してみたい機能
このゲームはスロットというよりただの絵合わせのゲームとなってしまいました
当時はスロットの確定演出などを取り入れたいと思いましたが、別のゲームジャム(バンダイナムコスタジオ杯2025)と並行して作成していたことと、当時unityにあまり慣れていなかったことがあって実装する時間がなく、絵合わせゲームとして展示をいたしました。
ですので、今後は演出に力を入れていきたいと思います。
